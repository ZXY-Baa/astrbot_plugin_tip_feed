# AstrBot 投喂收款码插件 说明文档

## 简介

**astrbot_plugin_tip_feed** 是一个为 [AstrBot](https://astrbot.app/) 设计的轻量级插件。  
当聊天消息中出现“投喂”等关键词时，机器人会自动发送预设的收款码图片，方便群友或好友进行打赏、赞助。

---

## 功能特性

- 🔍 **关键词触发**：监听所有消息，只要包含自定义关键词即触发（默认“投喂”）。
- 🖼️ **图片发送**：支持发送本地图片或网络图片 URL 作为收款码。
- ⚙️ **可视化配置**：通过 AstrBot WebUI 插件配置面板即可修改收款码路径，无需改代码。
- 📢 **友好提示**：若未配置收款码，会回复提示文字，避免机器人无响应。
- 📦 **开箱即用**：仅需三个文件即可运行，无需额外依赖。

## 安装步骤

### 1. 下载插件

将 `astrbot_plugin_tip_feed` 整个文件夹放入 AstrBot 的插件目录：

```text
AstrBot/data/plugins/astrbot_plugin_tip_feed/
```

如果手动创建，请确保包含上述四个文件。

### 2. 重启或重载插件

- 启动 AstrBot，进入 WebUI。
- 在 **插件管理** 页面找到 `astrbot_plugin_tip_feed`。
- 点击 **重载插件** 或重启 AstrBot 使插件生效。

### 3. 配置收款码

在插件管理页面点击该插件的 **配置** 按钮，填写 `收款码图片路径`：

| 配置项 | 类型 | 说明 |
|--------|------|------|
| `qrcode_path` | 字符串 | 收款码图片路径，支持本地绝对路径或图片 URL |

**示例：**

- 本地路径：`/home/user/qrcode.png` 或 `C:\Users\user\qrcode.jpg`
- 网络图片：`https://example.com/qrcode.png`

> ⚠️ 使用本地路径时，请确保 AstrBot 进程对该文件有读取权限。

### 4. 测试效果

在任意聊天窗口发送包含“投喂”的消息，例如：

```text
投喂一下
今天投喂你啦
```

机器人将自动回复你配置的收款码图片。若未配置，则回复：

```text
感谢投喂！但收款码还没配置好喵~ 请提醒管理员在插件配置中上传收款码图片。
```

## 配置详解

### `_conf_schema.json`

```json
{
  "qrcode_path": {
    "description": "收款码图片路径",
    "type": "string",
    "default": "",
    "hint": "支持本地文件路径（如 /path/to/qrcode.png）或图片 URL（以 http/https 开头）"
  }
}
```

- **description**：配置项在 WebUI 中显示的名称。
- **type**：数据类型，此处为字符串。
- **default**：默认值，空字符串表示未配置。
- **hint**：鼠标悬停或配置页面显示的提示信息。

## 使用说明

### 触发规则

- 消息文本中**任意位置**包含配置的任一关键词即触发。
- 默认关键词为“投喂”，可在插件配置中修改。
- 不区分大小写（中文无大小写），但会匹配“投喂”连续字符。
- 支持群聊、私聊等所有消息类型。

### 回复逻辑

1. 收到消息 → 提取纯文本。
2. 若文本包含“投喂” → 读取配置 `qrcode_path`。
3. 若路径非空 → 发送图片。
4. 若路径为空 → 发送提示文字。

### 自定义关键词

如果需要修改触发关键词（例如同时支持“打赏”、“赞助”），可编辑 `main.py`：

```python
# 原代码
if "投喂" not in message_str:
    return

# 修改为多个关键词
keywords = ["投喂", "打赏", "赞助"]
if not any(kw in message_str for kw in keywords):
    return
```

修改后重载插件即可。

## 常见问题

### Q1：发送图片失败怎么办？

- 检查本地路径是否正确，文件是否存在。
- 检查 AstrBot 进程是否有读取权限。
- 若使用 URL，确认网络可访问且图片格式受支持（jpg/png/gif 等）。
- 查看 AstrBot 日志中的错误信息。

### Q2：为什么配置了路径还是回复提示文字？

- 确认配置已保存，并重载了插件。
- 检查配置项名称是否为 `qrcode_path`，不要有多余空格。
- 若路径为本地文件，尝试使用绝对路径。

### Q3：可以同时发送文字和图片吗？

当前逻辑为：配置了图片则只发图片，未配置则只发文字。  
如需同时发送，可修改 `main.py`：

```python
yield event.plain_result("感谢投喂！")
yield event.image_result(image_path)
```

### Q4：支持多个收款码随机发送吗？

当前版本不支持。如需扩展，可在配置中增加数组类型，并在代码中随机选择。
